# ADR-0001: Record architecture decisions

- Status: Accepted
- Date: 2026-11-13

## Context
AeroGuide will grow over several stages and a later AI phase. Decisions about data integrity, providers and architecture need to be traceable.

## Decision
We use lightweight ADRs (Michael Nygard format) in `docs/decisions/`, numbered sequentially: `NNNN-kebab-title.md` with Status, Date, Context, Decision, Consequences. An ADR is never edited after acceptance except to update its status. Changes come as a new ADR that supersedes it.

## Consequences
Decisions can be reviewed in PRs. The index in `README.md` must be kept up to date.
